# Java Multithreading

Учебный Java-проект по многопоточности, синхронизации и координации потоков.

В исходниках находятся примеры создания и координации потоков, работы с общим
состоянием и применения механизмов синхронизации.

## Запуск

Требуется JDK и Maven:

```bash
./mvnw test
```

В Windows используйте `mvnw.cmd test`. Если тестов нет, соберите проект:

```bash
./mvnw package
```

## Что изучается

- жизненный цикл потоков;
- конкурентный доступ к данным;
- синхронизация операций;
- разделение задач между исполнителями.

Проект входит в учебный кластер портфолио.
